Common issues & simple solutions

01

Document is not showing

Check that you are using the correct issuer/service and that the details entered match the issuing authority's records. Try again later if the issuer service is temporarily unavailable.

02

OTP is not received

Check network connectivity, wait before requesting another OTP, and make sure the mobile number is the one registered with the relevant service.

03

Name/details do not match

Some services require your details to match the issuing authority's records. Check the spelling and other required details before trying again.

04

Upload or file problem

For a user-uploaded file, check the file format/size accepted by the service and make sure the connection is stable.

FREQUENTLY ASKED QUESTIONS

DigiLocker FAQ

What is DigiLocker?

DigiLocker is a Digital India platform for accessing, storing, sharing and verifying digital documents.

What is the difference between issued and uploaded documents?

Issued documents are provided by integrated government/issuer organisations. Uploaded documents are files that the user uploads to their DigiLocker Drive.

Are DigiLocker documents valid?

DigiLocker states that documents issued/shared through the platform can have legal validity equivalent to physical originals under the applicable rules.

What is a URI?

A URI is a Uniform Resource Identifier associated with an e-document in the DigiLocker ecosystem.

Can I access DigiLocker on mobile?

Yes. DigiLocker provides a mobile application as well as web access.

What should I do if my document cannot be fetched?

Check the selected issuer and required details, then retry. If the issue continues, use the official DigiLocker support route or ask the EverLocker author for educational guidance.
